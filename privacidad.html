2. Datos y funcionamiento del formulario

El formulario solicita nombre, empresa, correo profesional, teléfono, número aproximado de viviendas, fase del proyecto y un mensaje opcional. Los campos marcados como obligatorios son necesarios para preparar la solicitud. Evita incluir datos sensibles o datos de otras personas que no sean necesarios.

Al pulsar «Solicitar demo», los datos se envían de forma cifrada a Supabase y se guardan para atender tu solicitud. Resend envía un aviso a prospectus3d.es@gmail.com. Si el aviso falla, la solicitud permanece guardada y el sistema reintenta el envío. Cloudflare Turnstile verifica la interacción para reducir el spam. También se utilizan límites de envío y un identificador derivado del correo para controlar abusos. La web no guarda los datos del formulario en el almacenamiento del navegador.

3. Finalidades y bases jurídicas

Los datos recibidos se utilizan para responder a tu consulta, coordinar una demostración y, si lo solicitas, preparar una propuesta. La base es la aplicación de medidas precontractuales solicitadas por ti (artículo 6.1.b del RGPD). Cuando actúas como contacto profesional de una empresa, la base es el interés legítimo en atender esa relación profesional (artículo 6.1.f).

Este formulario no te suscribe a una lista de publicidad. La prestación técnica y la seguridad del sitio pueden implicar registros de conexión por parte del proveedor de alojamiento. No se realizan decisiones automatizadas ni perfiles comerciales mediante el código de esta web.

4. Conservación

Las consultas se conservarán mientras sea necesario para atenderlas y gestionar las actuaciones solicitadas. Una vez finalizadas, los datos se suprimirán o, cuando corresponda, se mantendrán bloqueados durante los plazos legales aplicables a posibles responsabilidades. Si se formaliza una contratación, se facilitará la información correspondiente a esa relación.

5. Proveedores y servicios externos

La web se aloja en GitHub Pages. Supabase almacena las solicitudes y ejecuta el procesamiento del formulario. Resend gestiona las notificaciones al buzón de Gmail de Prospectus. Cloudflare Turnstile proporciona la verificación antispam al interactuar con el formulario y puede tratar datos técnicos del navegador y de conexión. Estos proveedores tratan la información necesaria para prestar sus servicios. Los datos también podrán comunicarse a autoridades cuando exista una obligación legal.

La demo de Serra Residencial se aloja en Netlify y se carga automáticamente dentro de esta página, sin solicitar una activación previa. El navegador puede aplazar su carga hasta que te acerques a la sección de la demo. Al cargarla, tu navegador comunica a ese servicio tu dirección IP y datos técnicos de conexión. Los enlaces para abrirla en otra pestaña acceden directamente al sitio externo.

El botón de WhatsApp es un enlace: solo accedes a ese servicio al pulsarlo. Puedes contactar por correo o teléfono si prefieres no usar WhatsApp.

Estos proveedores pueden tratar datos fuera del Espacio Económico Europeo. Sus políticas describen los destinos y mecanismos de protección aplicables, incluidos, cuando proceda, decisiones de adecuación o cláusulas contractuales tipo.

6. Tus derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación y portabilidad cuando sean aplicables, escribiendo a prospectus3d.es@gmail.com. Indica el derecho que quieres ejercer; se podrá solicitar información adicional proporcionada si es necesaria para verificar tu identidad. Cuando un tratamiento se base en consentimiento, puedes retirarlo sin afectar a la licitud del tratamiento anterior.

También puedes presentar una reclamación ante la Agencia Española de Protección de Datos.
